# Laboratório de Conjuntos - Desenvolvimento de Software Multiplataforma (FATEC Osasco)

Repositório dedicado à atividade prática de Teoria dos Conjuntos, Conjuntos Numéricos e Integração (Mini-projeto de Controle de Acesso).

## 📂 Estrutura do Projeto
- **Parte 1 (`Parte1Conjuntos.java`):** Implementação manual das operações de conjuntos (união, interseção, diferença, diferença simétrica, pertinência, inclusão e complemento) utilizando laços e condicionais, com validação cruzada comparada à API nativa do Java.
- **Parte 2 (`Parte2ConjuntosNumericos.java`):** Classificador de números (ℕ, ℤ, ℚ, 𝕀, ℝ), tratamento de frações, dízimas periódicas com cálculo automático da fração geratriz, raízes e bônus (Crivo de Eratóstenes e divisores). Convenção adotada: 0 ∈ ℕ.
- **Parte 3 (`Parte3ControleAcesso.java`):** Sistema de controle de acesso por perfis utilizando teoria dos conjuntos, normalização de strings e validação automatizada dos cenários do gabarito oficial.
